# 원문 주장 검증표

고정 커밋의 [FlyGPT conclusions](https://github.com/QuixiAI/FlyGPT/blob/d8ce5e286b638167a0dcb51bd0e1defdbd510d37/conclusions.md)을 확인했다. 저장소의 자체 보고이며 독립 재현 결과는 아니다.

| 주장 | 확인 및 이번 연구의 처리 |
|---|---|
| 20k에서 평균 0.011 nats, 다섯 시드 모두 실제 배선 우세 | 원문 §2와 일치. 원 판정은 같은 부호와 평균 0.05 nats 이상을 함께 요구했으므로 유의한 배선 우월성으로 쓰지 않는다. 학습 속도 조사 동기다. |
| 최종 손실 1.609 대 1.613 | §3 베이스라인 표와 일치. §2 다섯 대응 시드의 최종 평균차는 0.003으로, 서로 다른 표를 같은 집계로 혼합하지 않는다. |
| FlyGPT가 과적합에 더 강함 | §3에서 관찰. 언어 순차 학습의 파국적 망각을 측정한 결과는 아니다. |
| 전체 CNS 모듈성이 전이를 돕는다 | §6의 후속 가설. 5k 중심뇌 모델에 입증된 기전으로 가져오지 않는다. |
| 49,393뉴런 고정 저수지 또는 52.8M 파라미터 | 이 계획의 cb5k와 다르다. 실제 고정 구조에서 524,324 연결 강도를 학습하는 5,000뉴런 모델을 사용한다. BPE·분류 헤드 변경 후 파라미터 수는 실행 로그에서 다시 계산한다. |
| 0.011 nats를 학습량 20% 감소로 해석 | 환산 근거 없음. 20%는 별도의 설계 검출 목표다. |
| bits/병렬문장이 보편적으로 공정한 언어 난이도 척도 | 보장되지 않는다. 표현 길이·분포 차이가 남는다. 본실험은 공통 의미 분류 과제의 정확도 도달 비용을 측정한다. |
| 소비자 GPU에서 며칠 안에 완료 | 검증되지 않음. 두 3080 Ti에서 전체 평가·저장·시험을 포함한 비용을 측정한다. |

[기존 커널 정합성 검사](https://github.com/QuixiAI/connectome-kernels/blob/c6be4cfea8ca2210098ef52344b88e85c683fd5c/tests/test_equivalence.py)는 CUDA가 없으면 skip하며, 짧은 길이와 마이크로스텝 1/2/3을 검사한다. 이번 G0는 장치 부재를 blocked로 반환하고 M=4·분류부·가변 길이·패딩·누적·실제 5k 경로를 추가한다. 기존 검사 통과 기록을 새 경로의 검증으로 대신하지 않는다.

통계 설계 참고: [시뮬레이션 연구 설계 원칙](https://arxiv.org/abs/1712.03198), [RMST 정의와 설계](https://link.springer.com/article/10.1186/1471-2288-13-152). 구현의 구체적인 DGM·허용 오류율·CV 근사 범위는 이 연구의 선택이며, 참고문헌이 그 선택의 타당성을 자동 보장하지 않는다.

결론 문장은 신뢰구간이 배제하는 비용 차이의 범위와 실제 미도달률을 제시한다. 작은 효과·일시적 효과가 없다고 쓰지 않으며, 살아 있는 초파리의 언어 이해나 CEFR 숙달을 주장하지 않는다.
