# 실행 프로토콜 v4

## 개정 v4-ai-review-1: Claude 단독 검수

사용자 결정으로 언어별 능숙자 2인의 사람 검수 요건을 Claude의 분리된 세션 2회씩,
총 6회 판정으로 대체한다. 이는 사람 검수나 통계적으로 독립된 평가자 검증이 아니다.
원판정 일치율 95%·κ 0.8은 AI 반복 일관성 기준으로 유지하며, 불일치·부자연스러움은
원응답을 보존하고 Claude의 별도 재검토로 해결한다. 실제 문항 오류는 새 데이터 버전으로
수정한다. 모델·프롬프트·입력·원응답·설정·시각과 재검토 이력을 해시로 연결한다.
미완성·합성·출처 미상 자료는 인증하지 않는다. 전체 절차·형식·한계는
[AI 검수 운영 안내](AI_REVIEW_GUIDE.md)를 따른다. 기존 사람 검수 문서는 과거 절차로 보존한다.

새 실행 설정은 `configs/protocol-v4-ai.json`이다. 본 개정은 언어 데이터 검증 방식만 바꾸며,
학습 임계값·평가 정책·시드 선택·검정력·GPU 예산을 완화하지 않는다. 결과에는
`review_mode=claude_only`, `human_reviewed=false`를 남긴다. AI의 공유 오류·언어별 편향은
남을 수 있으므로 AI가 검수한 이 통제 코퍼스에서의 학습 효율로만 해석한다.

## 연구 질문과 추정 대상

실제 cb5k 배선의 동일한 학습 가능한 모델에서 세 언어의 의미 과제별 도달 비용 및 여섯 순서의 동시 도달 비용을 비교한다. 대상은 이 문항·입력 표현·모델·학습 정책의 효율이다. 배선 비교는 보조 연구다.

## 고정 모델과 데이터

실제 배선 5,000뉴런·524,324엣지, 공유 byte BPE 4,096, 임베딩 32차원, 토큰당 마이크로스텝 2, 마지막 유효 토큰의 출력 뉴런 512개에서 이진 분류한다. 연결 강도·누출 계수·바이어스·입력·분류부를 처음부터 학습한다. 분류 교차엔트로피만 사용한다. fp32, AdamW 순환부 0.0003/입출력부 0.001, weight decay 0.01, clipping 1.0. 학습 중 언어 전환 때 모델·옵티마이저를 유지한다.

유효 배치 256, 동일 의미 ID 순서, 길이 정렬 마이크로배치. 배치 손실은 문항 수로 가중하고 문항을 자르지 않는다. 정규 평가·단계 상한·최종 상한과 보조 복습 체크포인트에서는 작은 경계 배치가 생긴다. 복습 0/100k/200k/300k의 배치 경계는 모든 순차 런에 동일하게 적용한다.

행위자·대상/부정/공간 관계/수량의 네 유형. 언어마다 train 20,000; dev A/B 각각 유형당 1,000; test 유형당 1,000. 총 96,000. 의미 궤도·오답·번역본·외곽 문장 틀 계열은 분할 간 공유하지 않는다. 이 정의는 내부 문법 규칙까지 미학습이라는 뜻이 아니다.

정당한 조사·격·어순과 길이·어휘 중복 지름길을 구분한다. 문법 기준선의 높은 정확도를 폐기 사유로 쓰지 않는다. 역할 과제는 두 동사의 행위자 결합을 판정하게 하여 한 문장의 조사 한 글자만 찾는 규칙으로 충분하지 않게 구성했다. 통제 코퍼스 밖 자연어 일반화는 별도 문제다.

## 평가와 종료

고정된 5,120/10,240/20,480 중 한 간격, 전체 A/B 패널 교대. 단일 언어는 4셀, 순차·혼합은 첫 시점부터 12셀. 각 셀 80% 이상을 **같은 연속 두 정규 시점**에 만족해야 한다. 도달 비용은 두 번째 시점까지 반복을 포함한 학습 노출량이다. 조건별 평균 정확도로 숙달을 대체하지 않는다.

마지막 공통 상한은 일정에 포함한다. 상한이 간격의 배수가 아니어도 추가 최종 평가를 하고, 바로 전 정규 평가와 두 번 통과하면 사건으로 기록한다. 단계 경계는 숙달 판정을 앞당기는 평가 기회가 아니다. 관측하지 않은 실제 교차 시점으로 보정하지 않는다.

단일 언어 상한 200,000. 순차 언어 단계당 상한 200,000, 현재 언어가 이미 두 번 통과한 상태면 0문항 이동 가능. 세 단계 후 1:1:1 복습. 순차·혼합 상한 900,000. 정규 평가에서 12셀 동시 숙달하면 즉시 주 런 종료. 독립 test는 종료 상태에 한 번만 적용한다.

## 설계 선택과 게이트

GPU 전 5,000회/시나리오 시뮬레이션. N=10/15/20, 효과 0/10/20/30%, 로그정규/Weibull, CV 0.25/0.5/1, 잠재 대응 상관 0/0.5/0.8, 미도달률 0.1/0.3/0.5, 평가 간격 세 개. 20%는 검출 목표이지 예상 효과가 아니다. 단조 교차 사건시간 모형이며 신경망 학습 동역학을 재현하지 않는다.

G0: 두 sm_86 GPU의 실제 backend/분류 경로 출력·모든 기울기, M=2/4, 길이·패딩·누적·평가 불변성. G1: 분리 시드 128문항, ≤2,000업데이트에서 전체 98%, 유형별 95%. G2: 언어별 미학습 조합의 네 유형 모두 숙달 반복. G3: 별도 시드 실제 혼합의 900k 내 동시 숙달. 모든 여섯 순서 파일럿. 개정 AI 검수 인증 및 코드·배선·토크나이저 해시 일치가 전제다.

현재 실행 게이트는 파일럿 미도달률의 단측 exact 95% 상한을 시뮬레이션 격자 바깥 방향으로 맞춘다. 5개 이상의 완전 대응 순서 시드가 있을 때 제한 비용 CV의 시드 부트스트랩 97.5% 상한에 25%를 추가한 근사 범위를 쓸 수 있다. 그렇지 않으면 모든 CV를 유지한다. 상관 0과 두 분포를 유지한다. 이는 파일럿으로 검정력이 보장된다는 뜻이 아니다.

최소 검정력 MC 하한 ≥80%, 영가설 FWER MC 상한 ≤6%, 평가 해상도 통과, 25% 여유를 포함한 GPU·달력 예산을 요구한다. 두 대비의 유리한 동시 유의성에 기대지 않도록 검정력 선택에서는 원 p<0.025 기준도 요구한다. 일부 모형의 오류율이 허용 범위를 넘으면 해당 설계는 승인되지 않는다.

평가 해상도의 구현상 허용치는 촘촘한 단일 언어 A/B 로그에서 언어 간 비용 차이 왜곡이 기준 평균 비용의 5% 이하라는 것이다. 같은 간격에서 실제 여섯 순서를 실행한 기록도 필요하다. 관측 효과 크기로 N을 선택하지 않는다. 사전 격자를 확장해야 하면 새 설계 버전으로 기록한다.

## 본실험과 분석

시드당 3 단일 언어 + 6 순서 + 1 혼합 = 10런. 모든 주 조건 실제 배선. 언어별 유형 도달·4유형 동시 도달을 구분한다. 두 확증 대비는 KO 마지막 두 순서 평균−첫 번째 두 순서 평균, EN/DE 인접 네 순서 평균−분리 두 순서 평균. 부호는 비용 차이이며 양측 검정한다.

공통 상한에서만 행정적 검열이면 제한 비용 min(T,상한)의 시드 평균이 RMST다. 기술 실패를 이 값으로 대체하지 않는다. 대비를 시드 안에서 계산한 뒤 대응 t 검정과 Holm 보정한다. 코드의 동시 신뢰구간은 두 대비 Bonferroni 97.5% t 구간이며, 시드 블록 부트스트랩 95% 구간은 민감도 분석이다. 전량 미도달·분산 0이면 정보 부족을 기록한다. p값이 크다는 이유로 동등성을 선언하지 않는다.

`*-forgetting.json`은 정규 전체 패널에서 해당 셀의 과거 최고 정확도 대비 하락을 기록한다. A/B 표본차이도 포함하므로 이것만으로 인과적 망각량이나 순수 전이를 단정하지 않는다. 여섯 순서 개별 곡선과 혼합 기준선을 모두 보고한다.

## 결과 동결과 변경

`freeze`는 모든 근거 파일 해시, 코드·배선·토크나이저·데이터·설정 해시, 전체 런 목록을 고정한다. 변경되면 실행을 거절한다. 본실험 결과 확인 후 임계값·과제·유리한 순서를 변경하지 않는다. 실패한 파일럿도 보존한다. 연구계획을 충족하지 못하면 확증실험 대신 파일럿 결과와 필요한 추가 자원을 산출한다.
