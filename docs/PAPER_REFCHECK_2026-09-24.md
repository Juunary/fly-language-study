## Summary of required fixes

1. **lappalainen2024** (major/factual): author list contains two fabricated names (Shcherbakov, Vasilakis), one misattributed name (Nenadic → should be Gruntman), and is missing a real co-author (Macke, Jakob H.). This is the most serious error in the file — it fabricates named contributors to a real Nature paper.
2. **sennrich2016** (content-attribution in main.tex, not the bib record itself): the manuscript's prose calls its tokenizer "byte-level BPE" while citing only Sennrich et al. 2016, who introduced character-level BPE. Either the wording or the citation should change.
3. **henderson2018**, **agarwal2021**: missing page numbers in the bib (3207–3214 and 29304–29320 respectively) — not wrong, just incomplete.
4. **flygpt**: the author field names an organization ("QuixiAI") that is a single-person GitHub org with no public roster; the repo's own README asks to be cited as "Hartford (2026)." The bib's MIT-licence note should be understood as covering the code only (the connectome data itself is CC-BY 4.0). The manuscript's "reports learning advantages" phrasing cites the repo's early-training/regularization framing but omits the repo's own primary "no detectable difference at full training" conclusion — worth a caveat, though the manuscript does separately note it audited rather than assumed these claims (Appendix~\ref{app:history}).
5. **scheffer2020**: correct as a bib record, but jointly citing it with dorkenwald2024 under "Whole-brain fly connectomes are now available" slightly overstates its scope — scheffer2020 is a central-brain (hemibrain-type) reconstruction, not whole-brain.
