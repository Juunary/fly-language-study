# Overleaf project: Cognitive Systems Research submission (Elsevier elsarticle)

Upload this folder as a zip (Overleaf: New Project > Upload Project) or sync it from GitHub. Compiler: **pdfLaTeX**,
main document `main.tex`. Everything needed is inside this folder:

| File | Purpose |
|---|---|
| `main.tex` | manuscript (`\documentclass[preprint,12pt,authoryear]{elsarticle}`, line numbers on; for the journal look use `[final,3p,times,authoryear]`) |
| `refs.bib` | references (author-year, `elsarticle-harv`) |
| `elsarticle.cls`, `elsarticle-harv.bst` | Elsevier class and bibliography style (CTAN `elsarticle`, generated from the .ins) |
| `figures/*.png` | aggregate figures from `scripts/analyze_main_truncated.py` |
| `tables/*.tex` | table bodies generated by `scripts/paper_tables.py` from the frozen analysis (do not edit by hand) |
| `latexmkrc` | pdfLaTeX + BibTeX for latexmk/Overleaf |

Korean text uses `\usepackage{kotex}` (cjk-ko, in TeX Live full, which Overleaf provides; Nanum Type1 fonts).
Table bodies are read with the primitive `\@@input` (macro `\tablebody`) because LaTeX's `\input` inserts file hooks
that break `\bottomrule` after the last row. Wide tables are scaled with `\resizebox` to the 12pt preprint text width.

Before submission fill in the placeholders in the frontmatter (`[email]`, `[Department, Institution]`, `[City]`,
`[Country]`) and check the Funding and CRediT statements.
