# 본실험 계획·판단 기록 (프로토콜 v5 계열) — 작성 중, 2026-09-17

이 문서는 탐색 종료 뒤 본실험(확증 실험)까지의 판단을 순서대로 기록한다. 각 절은 근거 파일을 명시하며,
결과를 보고 임계값·상한·과제를 바꾸지 않는다. 미완 항목은 "진행 중"으로 표시한다.

## 1. 탐색 정리 (v1–v5)

- 탐색 v1–v5(`reports/FRAME_DIAGNOSTIC_V1.md`, `EXPLORATORY_V2.md`, `EVALUATION_REVISION_V4.md`,
  `EXPLORATORY_V3_WORDBOUND.md`, `EXPLORATORY_V4_WORDBOUND_ATTAINMENT.md`, `EXPLORATORY_V5_WORDBOUND_ORDER.md`)는
  모두 탐색 자료이며 본실험 표본에 포함하지 않는다(시드 20001–20003, 검수 인증·확증 시험셋 없이 수행).
- v5 도달 시점은 저장된 정기 패널 곡선에서 재계산해 14런 모두 보고서와 일치함을 확인했다
  (`EXPLORATORY_V5_WORDBOUND_ORDER.md` 8절).
- 마지막으로 확정된 셀은 혼합 두 런 모두 **KO 공간**이었고, 순차 런에서는 첫 언어의 수량이 8런, 그 외는 EN 공간·EN 수량·
  DE 공간·KO 수량이었다. "수량이 항상 마지막 병목"이라고 말하지 않는다.
- 뒤 언어의 빠른 숙달은 언어 지식의 전이만으로 해석하지 않는다. 언어와 무관한 과제 지식의 재사용, 추가 최적화 상태에서의
  시작, 첫 단계에만 긴 노출을 주는 전환 정책이 섞여 있고, 첫 단계 동안 다른 언어 정확도는 우연 수준이었다.
- 두 시드의 순서 순위(KO 먼저가 빠름, EN 먼저가 늦음)는 확정된 최적 순서가 아니다. 본실험은 사전 지정 두 대비와 시드 수로 검정한다.

## 2. 본실험 설정 고정 — 프로토콜 v5.1 (2026-09-17)

`docs/PROTOCOL_V5.md`가 고정 설정을 적는다. v5.0(자료 v4.5, 어휘 841)은 1차 검수의 문장 틀 지적으로 인증할 수 없어
같은 날 v5.1로 정식 개정했다(문서 "v5.1 개정" 절). 바뀐 것은 자료(`data/draft-v4.6`, 표면형만 개정, 의미 궤도·분할·
정답·순서는 v4.5와 동일)와 입력(`artifacts/tokenizer-wordbound-v4.6.json`, 실제 어휘 832)뿐이며, 간격 5,120·상한
200,000/900,000·임계 0.8·패널 1,000·학습률·배치 256·마이크로스텝 2·시드 목록은 v5.0 그대로다. 설정 파일
`configs/protocol-v5.1.json`, 코드 기본값(`Protocol`, `validate_primary_model`=832), 실행 검사, 분석 코드가 같은 값을 쓴다
(`tests/test_protocol_v5.py`). 이 개정은 확증 실험을 하나도 실행하기 전의 개정이며, 결과를 보고 바꾼 것이 아니다.

### 3.2 Claude 단독 검수 1차 (review/v5, data/draft-v4.5) — 인증 불가, 자료 개정으로 이어짐

- 세션: Claude Code 하위 에이전트 6개(모델 식별자 `claude-opus-5[1m]`, 2026-09-16T22:25Z–22:58Z), 언어별 200문항 + 21행 체크리스트.
  실행 기록 JSONL·원응답·검증 결과는 `review/v5/ai/claude-v5/`(비공개)에 있고 `scripts/record_ai_review_session.py`가 기록했다.

  시도가 끊긴 뒤 완전한 응답을 처음부터 다시 냈다(대체된 시도와 최종 응답 사이 판정 불일치 0건). 규칙은 `docs/AI_REVIEW_GUIDE.md`.

- 병합(`review/v5/submissions/merged-ai-v5`): 언어별 두 세션의 일치율 1.0, κ 1.0, 정답과 다른 판정 0건. 미해결 65건은 모두

## 4. 표본 크기 사전 시뮬레이션 (승인 기준 재사용)

- 격자: `artifacts/power/final-grid.jsonl`(3,888행, 시나리오당 5,000회, `complete=true`, 설계 효과 0.2, 최소 검정력 0.8,
  Wilson 95% MC 구간). 요약: `reports/power-summary.json`.
- 승인 기준(`docs/PROTOCOL_V4.md`, v5 유지): 검정력 MC 하한 ≥ 0.80, 영가설 FWER MC 상한 ≤ 0.06, 파일럿 미도달 상한이
  격자 안, 평가 해상도 통과, 25% 여유 예산. 관측 효과로 N을 고르지 않는다(`flystudy.workflow.design_decision`).
- 평가 간격 5,120, 잠재 상관 0에서 효과 0.2의 보수적 검정력 하한(및 효과 0의 FWER 상한, 표 생략 시 ≤ 0.066):

| N | 분포 | 기준 제한 CV | 검열 | 검정력 하한 |
|---|---|---|---|---|
| 10 | lognormal | 0.126 / 0.166 / 0.213 | 0.5 / 0.3 / 0.1 | 0.881 / 0.787 / 0.636 |
| 10 | weibull | 0.168 / 0.202 / 0.232 | 0.5 / 0.3 / 0.1 | 0.749 / 0.662 / 0.596 |
| 15 | lognormal | 0.126 / 0.166 / 0.213 / 0.221 | 0.5 / 0.3 / 0.1 / 0.5 | 0.985 / 0.946 / 0.863 / 0.692 |
| 15 | weibull | 0.168 / 0.202 / 0.232 / 0.301 | 0.5 / 0.3 / 0.1 / 0.5 | 0.931 / 0.884 / 0.826 / 0.488 |
| 20 | lognormal | 0.126 / 0.166 / 0.213 / 0.221 / 0.297 | 0.5 / 0.3 / 0.1 / 0.5 / 0.3 | 0.998 / 0.989 / 0.955 / 0.839 / 0.675 |
| 20 | weibull | 0.168 / 0.202 / 0.232 / 0.301 | 0.5 / 0.3 / 0.1 / 0.5 | 0.983 / 0.961 / 0.940 / 0.637 |

- 해석: CV ≈ 0.21–0.23 이하(파일럿이 제한하는 산포 상한)에서 N=15는 두 분포 모두 0.8을 넘고, N=10은 lognormal의
  가장 낮은 CV에서만 넘는다. CV ≥ 0.30이면 N=20도 부족하다. 실제 판정은 파일럿의 산포 상한(부트스트랩, 바깥쪽 반올림)과
  미도달 상한을 넣어 `assess-design`이 내린다. v5 탐색의 두 시드 분산을 모집단 분산으로 쓰지 않는다.
- 효과 0/10/20/30% 모두 격자에 있으며 결과 보고에 함께 적는다.
