# 본실험 계획·판단 기록 (프로토콜 v5 계열) — 작성 중, 2026-09-17

이 문서는 탐색 종료 뒤 본실험(확증 실험)까지의 판단을 순서대로 기록한다. 각 절은 근거 파일을 명시하며,
결과를 보고 임계값·상한·과제를 바꾸지 않는다. 미완 항목은 "진행 중"으로 표시한다.

## 1. 탐색 정리 (v1–v5)

- 탐색 v1–v5(`reports/FRAME_DIAGNOSTIC_V1.md`, `EXPLORATORY_V2.md`, `EVALUATION_REVISION_V4.md`,
  `EXPLORATORY_V3_WORDBOUND.md`, `EXPLORATORY_V4_WORDBOUND_ATTAINMENT.md`, `EXPLORATORY_V5_WORDBOUND_ORDER.md`)는
  모두 탐색 자료이며 본실험 표본에 포함하지 않는다(시드 20001–20003, 검수 인증·확증 시험셋 없이 수행).
- v5 도달 시점은 저장된 정기 패널 곡선에서 재계산해 14런 모두 보고서와 일치함을 확인했다
  (`EXPLORATORY_V5_WORDBOUND_ORDER.md` 8절).
- 마지막으로 확정된 셀은 혼합 두 런 모두 **KO 공간**이었고, 순차 런에서는 첫 언어의 수량이 8런, 그 외는 EN 공간·EN 수량·
  DE 공간·KO 수량이었다. "수량이 항상 마지막 병목"이라고 말하지 않는다.
- 뒤 언어의 빠른 숙달은 언어 지식의 전이만으로 해석하지 않는다. 언어와 무관한 과제 지식의 재사용, 추가 최적화 상태에서의
  시작, 첫 단계에만 긴 노출을 주는 전환 정책이 섞여 있고, 첫 단계 동안 다른 언어 정확도는 우연 수준이었다.
- 두 시드의 순서 순위(KO 먼저가 빠름, EN 먼저가 늦음)는 확정된 최적 순서가 아니다. 본실험은 사전 지정 두 대비와 시드 수로 검정한다.

## 2. 본실험 설정 고정 — 프로토콜 v5.1 (2026-09-17)

`docs/PROTOCOL_V5.md`가 고정 설정을 적는다. v5.0(자료 v4.5, 어휘 841)은 1차 검수의 문장 틀 지적으로 인증할 수 없어
같은 날 v5.1로 정식 개정했다(문서 "v5.1 개정" 절). 바뀐 것은 자료(`data/draft-v4.6`, 표면형만 개정, 의미 궤도·분할·
정답·순서는 v4.5와 동일)와 입력(`artifacts/tokenizer-wordbound-v4.6.json`, 실제 어휘 832)뿐이며, 간격 5,120·상한
200,000/900,000·임계 0.8·패널 1,000·학습률·배치 256·마이크로스텝 2·시드 목록은 v5.0 그대로다. 설정 파일
`configs/protocol-v5.1.json`, 코드 기본값(`Protocol`, `validate_primary_model`=832), 실행 검사, 분석 코드가 같은 값을 쓴다
(`tests/test_protocol_v5.py`). 이 개정은 확증 실험을 하나도 실행하기 전의 개정이며, 결과를 보고 바꾼 것이 아니다.
