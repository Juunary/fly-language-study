# 탐색 v1 문장 틀 진단: 원본 문장 vs 평서문 (연구 증거 아님)

`reports/TOKEN_EXPOSURE_V1.md`의 첫 서버 작업. 기존 5개 런의 `primary.pt`로 dev A/B를 원본 문장과
`assertion_view(row)` 평서문으로 각각 평가했다. 새 학습·파라미터 업데이트·데이터 수정·test 분할 평가는 없다.
평서문은 외곽 틀 보류 요건을 완화하므로 확증 평가가 아니며, 기존 숙달·종료 시점과 독립 시험 결과는 그대로다.
재현 도구: `scripts/frame_diagnostic_eval.py`. 수치: `reports/frame-diagnostic-v1.json`.

## 검증

- 입력(CPU): dev A/B 각 12,000행 모두 scene·ID·meaning_id·label 등 문장 외 필드가 같았다. `render()`로 원본
  sentence_a/b를 다시 만들면 전부 똑같다. 따라서 평서문은 외곽 틀만 다르다. 평서문 쌍 중 학습 쌍과 겹치는 것은 0,
  학습에 있는 meaning_id도 0이다.
- 체크포인트: 5개 모두 `independent-test.json`의 checkpoint_hash와 같고, 코드·데이터·토크나이저·그래프·프로토콜 해시도
  탐색 매니페스트와 같다. 평가는 `immutable_evaluation` 안에서 했고 파라미터·버퍼 변화 검사를 통과했다.
- 재현: 5개 모두 원본 dev B 점수가 상한에서 기록된 마지막 정기 패널(dev B)의 정답 수와 셀마다 정확히 같았다.
- 보존: 데이터·토크나이저·그래프·매니페스트와 런별 체크포인트·summary·independent-test·events·metadata
  39개 파일의 SHA-256이 평가 전후 같았다.

## 비용

평가 시작 때 GPU 0에서 돌던 다른 계산 작업은 없었고, 끝나지 않은 장부 예약도 없었다. 예비비에서 `explore-v1-frame-diagnostic-1`로
0.25 GPU시간을 예약했다. GPU 0(RTX 3080 Ti) 한 대에서 배치 256으로 5개 체크포인트를 차례로 평가했다.
실제 시간은 **0.0073 GPU시간(26.3초)**이다. CPU 준비와 해시 검사가 포함되며, 실패나 중단은 없었다(completed).
장부 누적 사용량은 0.397 / 672 GPU시간이고, 그중 예비비 사용은 0.364 GPU시간이다.

## 해석 (탐색적, 범위 제한)

- **KO(단일·혼합·순차 모두)**: 원본은 0.50–0.55이고, 평서문은 0.87–1.00이다. 평서문 값은 같은 체크포인트의
  학습 문항 정확도와 거의 같다(단일 KO: 0.891/0.999/1.000/0.899 vs dev A 0.885/0.997/1.000/0.893). 원본에서 KO는
  한 부류로 몰아 예측했다. 예를 들어 dev B의 KO 셀은 모든 런에서 1000/1000이 양성 예측이었다. 계획서 6항 기준으로
  "평서문에서만 높은" 경우다. 학습 틀로 표현하면 새 의미 조합에서도 학습 문항 수준의 정확도가 나오므로, 입력 표현이나 외곽 틀 변화가
  주요 조사 대상이다. 이 진단에서는 외곽 틀·길이(약 3배)·미노출 토큰 ID가 함께 바뀌므로 셋 중 무엇이 원인인지 가를 수 없다.
- **EN/DE 단일**: 두 보기 모두 우연 수준이다(0.46–0.53). 학습 문항 정확도도 0.52–0.55이므로 200k 노출 안에서
  학습 자체가 되지 않은 것이고, 외곽 틀로 설명되지 않는다. 최적화나 장기 학습 문제는 그대로 남는다.
- **혼합·순차의 EN/DE**: 원본은 0.47–0.55, 평서문은 혼합 EN 0.53–0.97·DE 0.81–0.92, 순차 EN 0.51–0.83·DE 0.55–0.80이다.
  순차 런의 EN/DE 평서문 값은 학습 문항 정확도보다 셀별로 0.02–0.08 낮다. EN 공간은 두 다국어 런 모두 평서문에서도
  0.51–0.55이고, 순차 학습 문항에서도 0.594로 낮았다.
- 여러 평서문 셀이 dev A와 dev B 모두에서 0.80을 넘었다. 그러나 이는 보류 요건을 완화한 한 시점의 진단이므로
  숙달 판정이나 정기 패널이 아니다. 임계값이나 언어별 설정 선택에 사용하지 않는다.
- 새 학습 여부는 이 진단을 바탕으로 따로 결정한다. 후속 데이터에서는 같은 표현 분포의 일반화와 미학습 외곽 틀 전이를
  별도 평가로 나누고, 입력 표현을 바꾸면 모든 언어를 같은 새 조건에서 비교한다.
