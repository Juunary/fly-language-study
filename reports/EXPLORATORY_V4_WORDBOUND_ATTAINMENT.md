# 탐색 실험 v4 — 단어 경계 BPE의 도달 시간과 재현성 (6런, 연구 증거 아님)

작성일 2026-09-17. 미사용 탐색 시드 **20002·20003** 각각에서 EN·DE·KO 단일 언어를 처음부터 학습한 6런이다. `study_evidence=false`. 여섯 순서 실험은 추가하지 않았고, 상한·임계값은 바꾸지 않았다.

- 입력: `artifacts/tokenizer-wordbound-v4.4.json` — `draft-v4.4` 학습 파일(v4.3과 바이트 동일, `6c885700…`)로 다시 학습해 `tokenizer-wordbound-v1`과 **해시 동일**(`24589e33…`)임을 확인한 뒤 메타데이터를 v4.4 dataset_hash에 연결했다. 실제 어휘 841, 파라미터 570,710. 검사 우회·기존 산출물 덮어쓰기 없음.
- 평가: `draft-v4.4` 주 표현(평서문). 학습 시작부터 **5,120문항 간격**으로 해당 언어의 전체 주 평가 패널 A/B를 번갈아 평가하고, 네 유형 각각 ≥0.80을 **연속 두 정규 평가**에서 만족하면 종료(기존 `Curriculum` 규칙). 상한 200,000. 초기(0문항) 평가는 하지 않았다.
- 유지: 실제 배선, 학습 문항, 학습률(0.0003/0.001), 배치 256, 마이크로스텝 2. 프로토콜 `configs/protocol-v4-ai-wordbound-5120.json`(`vocab_size=841`, `eval_interval=5120`; 나머지 v4-ai와 동일). 코드 해시 `7e43d57ca229…`(이 커밋).
- 독립 시험셋 미사용: 탐색(smoke) 런에 한해 종료 시 독립 시험을 생략하는 `independent_test=False`와 정기 시점의 보조 평가를 생략하는 `auxiliary_panels=False`를 `train.run`에 추가했다(연구 코호트는 둘 다 거부; 테스트로 확인). 보조(외곽 틀) 평가는 종료 체크포인트에서만 스크립트가 수행했다.

재현 도구: `scripts/exploratory_wordbound_attainment.py` (`--plan`, `--execute [--retry]`, `--report`). 수치: `reports/exploratory-v4-wordbound-attainment.json`. 학습 곡선 그림: `reports/figures/exploratory-v4-wordbound-attainment/*.png`. 런 산출물 `runs/exploratory-v4-wordbound-attainment/`(저장소 미포함).

## 5. 해석 (탐색적)

- v3 보고서가 추정한 "단일 언어 도달 비용이 첫 평가 간격 부근으로 몰릴 가능성"은 관측과 다르다. 5,120 간격·0.80 임계값·연속 두 통과 규칙에서 4유형 동시 도달 비용은 153,600–200,000이었고 6런 중 3런은 200,000 안에 도달하지 못했다. 도달 시간은 측정 가능한 범위에 있고 시드 간 편차와 유형 간 차이(수량 병목)가 크다. v3 보고서의 해당 문구는 정정했다.
- 수량 유형은 다른 세 유형이 1.0에 이른 뒤에도 0.6–0.9에 머문다. v2(whole-string)에서는 수량이 오히려 가장 빨랐으므로(EN/KO 600k에 0.98+), 단어 경계 입력에서 수 표현("two/three…", "zwei/drei…", "두/세… 마리")의 학습이 늦는 원인은 별도 점검 대상이다.
- 이 결과는 탐색용이며, 검수 인증·확증 시험셋·G0/G1 재검증 없이 얻었다. 임계값·상한을 조정하지 않았고 여섯 순서 실험은 포함하지 않았다.
