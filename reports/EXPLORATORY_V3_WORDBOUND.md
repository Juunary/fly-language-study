# 탐색 실험 v3 — 단어 경계 보존 BPE vs whole-string BPE (연구 증거 아님)

작성일 2026-09-17. 비교 하나만 실행했다: 공유 byte-level BPE를 **공백 경계를 넘어 병합하지 않도록**(`ByteLevel use_regex=True`) 같은 세 언어 학습 데이터로 만들고, EN·DE·KO 단일 언어를 처음부터 시드 20001로 학습해 탐색 v2(whole-string BPE)와 같은 노출 체크포인트에서 비교했다. 배선·학습률·배치 256·마이크로스텝 2·프로토콜(`protocol-v4-ai-mono900k`, 상한 900k)은 v2와 같고, 과제 단순화·한국어 문장 수정·학습률 변경은 하지 않았다. 기존 데이터·체크포인트·보고서는 보존했고, 새 조건도 `study_evidence=false`다. 코드 해시 `49e1b52ec63b…`(v4.4 개편 커밋에 `train_tokenizer`의 경계 옵션만 추가). 독립 시험셋은 쓰지 않았다.

재현 도구: `scripts/exploratory_tokenizer_boundary.py` (`--train-tokenizer`, `--profile`, `--plan`, `--execute [--retry]`, `--evaluate`). 수치: `reports/exploratory-v3-wordbound-report.json`, `reports/token-exposure-wordbound-v1.json`. 런 산출물 `runs/exploratory-v3-wordbound/`(저장소 미포함).

## 1. 토크나이저 (`artifacts/tokenizer-wordbound-v1.json`, 해시 `24589e33…`)

| 항목 | 단어 경계 BPE (이번) | whole-string BPE (연구 기본, v4.3) |
|---|---:|---:|
| 요청 어휘 / 실제 어휘 | 4,096 / **841** (부족분 3,255, 채우지 않음) | 4,096 / 4,096 |

보조 평가의 미노출은 외곽 틀 단어("Is it true that", "Stimmt es, dass", "사실인가")가 학습에 없어 바이트 조각(`I`,`s`,`_i`,`t`,`r`,`ue`,`?` 등, EN은 11종)으로 쪼개진 것이고, 내용어는 모두 학습에서 본 단어 단위 토큰이다. 기존 BPE에서는 내용어가 틀 조각과 융합돼 미노출 토큰이 되었다.

**한계(명시):** 어휘 수(841 vs 4,096)와 임베딩 파라미터 수가 다르므로 이 비교는 순수한 경계 효과가 아니라 **입력 표현 정책 전체의 비교**다. 어휘를 841로 맞춘 whole-string BPE를 CPU에서 만들어 보면 그것도 공백을 넘는 토큰이 293개 생기고 인코딩이 단어 경계판과 한 문항도 같지 않으므로, 어휘 수를 맞추는 것만으로 두 정책이 일치하지는 않는다(학습 실험은 하지 않았다).

## 4. 해석 (탐색적)

- **같은 틀의 새 의미 조합(주 평가)은 단어 경계 BPE에서 세 언어 12셀 모두 200k(수량은 300k)에 1.000**이다. v2에서 900k까지도 실패했던 EN 공간(0.59), DE 역할(0.72), DE 공간(0.58)이 모두 해소됐고, KO도 200k에서 역할 0.88→1.00, 수량 0.90→0.92(300k에 1.00). 손실은 세 언어 모두 649–706 업데이트(약 170–180k 노출)에서 0.1 아래로 내려갔다. v1/v2 진단이 지적한 "결정 단어가 인접 명사와 융합된 토큰" 구조가 사라지자 새 조합으로의 전이가 즉시 나타났다.
- **외곽 틀 전이(보조 평가)는 여전히 되지 않으며, 오히려 우연 이하인 셀이 많다**(DE 공간 dev B 0.12, EN 부정 dev B 0.30). 틀 단어의 미노출 바이트 조각이 체계적 오답을 유도하는 것으로 보이나 원인은 확정하지 않는다. 외곽 틀 전이는 토크나이저로 풀리는 문제가 아니라 별도 설계 문제로 남는다.
- **한계:** 어휘 841·파라미터 570,710으로 v2(4,096·674,870)와 달라 입력 표현 정책 전체의 비교다. 단일 시드·단일 런이며 검수 인증·확증 시험셋 없이 수행한 탐색이다. 주 평가는 200k 체크포인트에서 포화한 상태였으나, 이후 탐색 v4(`reports/EXPLORATORY_V4_WORDBOUND_ATTAINMENT.md`, 시드 20002·20003, 5,120 간격, 상한 200,000)에서 실측한 4유형 동시 도달 비용은 153,600–200,000이고 6런 중 3런은 200,000 안에 도달하지 못했다(수량 병목). 따라서 도달 비용이 첫 평가 간격 부근으로 몰린다는 이전 추정은 관측과 다르며 정정한다(2026-09-17).
- 임계값·언어별 설정은 바꾸지 않았고, 이 결과를 새 기준의 확증 결과로 보지 않는다.

## 5. 다음 실험 제안 (하나)

**단어 경계 BPE로 순차(en→de→ko)와 혼합 런을 v1과 같은 구조(시드 20001, 900k 상한, 정기 패널은 v4.4 주 평가)로 한 번 실행**한다. 목적은 이 표현에서 언어 전환 후 잊힘·전이가 나타나는지 확인하는 것이다(단일 언어 도달 비용은 탐색 v4에서 153,600–200,000·미도달 3/6으로 실측됐으므로 '첫 간격 포화' 여부는 더 이상 쟁점이 아니다; 2026-09-17 정정). 예상 비용은 v1 다국어 런(0.11–0.19 h)의 약 3배(토큰 길이)로 런당 0.4–0.6 h, 처리량 측정으로 재산정한다. 정기 패널을 v4.4 주 평가로 두면 숙달 시 루프가 독립 시험을 자동 실행하므로, 실행 전에 test 미사용 방침(스크립트에서 상한 한 업데이트 전 정지 또는 명시적 예외 기록)을 먼저 정한다. 어휘 수 통제(whole-string 841)나 토크나이저 채택 결정은 이 실험 결과 뒤로 미루며, 범위를 자동으로 넓히지 않는다.
